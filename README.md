# Object-Oriented Design Interview Guide

An original, responsive study guide for low-level and object-oriented design interviews.

## Coverage

- 7 foundations: OOP, analysis and design, UML, use case, class, sequence, and activity diagrams
- 16 project blueprints, from Parking Lot and ATM to a brokerage and social networks
- Requirements, domain models, flows, API sketches, design decisions, edge cases, and interview prompts
- Search, difficulty filters, reading progress, and persistent light/dark mode

## Run locally

Serve the `dist` directory with any static file server, for example:

```bash
python3 -m http.server 8766 --directory dist
```

Then open `http://127.0.0.1:8766/`.

## Content note

All explanations and examples in this repository were independently written for this guide. Third-party course pages and PDFs are not included.
